# Bubble Blast — art & audio pipeline

Every icon, sound and music loop in this repository is **generated by a script in
`tools/`**, which means nothing is an opaque binary blob: tweak the script, run it,
and the assets are rebuilt. Both scripts are plain Python 3 and need no design
tools.

## 1. Icons — `tools/generate_icons.py`

```bash
pip install numpy
python3 tools/generate_icons.py
```

What it writes:

| Output | Contents |
| --- | --- |
| `app/src/main/res/drawable/ic_*.xml` | 17 vector drawables: `ic_star`, `ic_star_empty`, `ic_coin`, `ic_plus_circle`, `ic_back`, `ic_lock`, `ic_pause`, `ic_gear`, `ic_gift`, `ic_aim`, `ic_color_drop`, `ic_bomb`, `ic_sound_on/off`, `ic_music_on/off`, `ic_logo` |
| `app/src/main/res/drawable/ic_launcher_background|foreground.xml` | adaptive icon layers |
| `app/src/main/res/mipmap-anydpi-v26/ic_launcher*.xml` | adaptive icon descriptors (API 26+) |
| `app/src/main/res/mipmap-{m,h,xh,xxh,xxxh}dpi/ic_launcher*.png` | legacy launcher bitmaps (API 24–25) |
| `store/icon_512.png` | Play Store icon (512×512) |
| `store/feature_graphic.png` | Play Store feature graphic (1024×500) |
| `tools/out/icon_sheet.png` | contact sheet, for eyeballing all icons at once |

The script contains a **miniature SVG renderer** (paths, arcs, cubic and quadratic
curves, fills, strokes, anti-aliasing via supersampling) plus a dependency-free PNG
writer, so the same vector definition feeds both the Android vector XML and the
store bitmaps. Icons are drawn on a 24×24 viewport; the launcher icon re-uses the
logo paths inside a 108×108 adaptive canvas.

**Changing an icon:** edit its path list in `create_icon_definitions()`, re-run the
script, and check `tools/out/icon_sheet.png` (open it in the IDE/Preview) before
building. Nothing else in the project needs to know.

## 2. Audio — `tools/generate_audio.py`

```bash
pip install --break-system-packages numpy soundfile   # libsndfile must be present
python3 tools/generate_audio.py
```

What it writes to `app/src/main/res/raw/` (mono, 22 050 Hz, OGG Vorbis):

| File | Length | Used for |
| --- | --- | --- |
| `sfx_shoot.ogg` | 0.13 s | firing a bubble |
| `sfx_pop.ogg` | 0.09 s | bubble pop (played with a rising pitch per combo) |
| `sfx_drop.ogg` | 0.36 s | cluster falling |
| `sfx_combo.ogg` | 0.32 s | combo milestone |
| `sfx_powerup.ogg` | 0.36 s | any power-up |
| `sfx_star.ogg` | 0.63 s | star reveal / reward |
| `sfx_level_complete.ogg` | 0.86 s | level complete fanfare |
| `sfx_game_over.ogg` | 1.74 s | game over |
| `sfx_click.ogg` | 0.04 s | every UI button |
| `music_home.ogg` | 10.0 s | menu music loop |
| `music_game.ogg` | 7.7 s | in-game music loop |

Both music loops have a length that is an exact number of bars (96 BPM and
124 BPM respectively), so they repeat seamlessly. All SFX are synthesised from
oscillators and shaped noise, normalised to −1.5 dBFS, and fade at both ends so
they never click.

**Replacing the audio with real recordings:** overwrite the file with the same
name using any OGG/MP3 file. If you switch to MP3, either keep the `.ogg`
extension off the resource table by renaming it consistently with
`AudioManager.Sfx`'s `resId` mapping, or simply re-encode to OGG — no code change
is needed as long as the resource name stays the same.

## 3. Fonts

The game deliberately uses the platform font stack (`sans-serif` family plus the
Material text appearances in `res/values/themes.xml`). Nothing is bundled, which
keeps the APK small and makes the text render with the device's own language
coverage. To add a custom font, drop the file into `res/font/` and point a
`TextAppearance` at it — the layouts already use styles rather than hard-coded
type.

## 4. Sound behaviour

`audio/AudioManager.kt` owns the mix:

* a `SoundPool` with 8 concurrent streams for SFX, per-effect volume from the
  `Sfx` table, and a playback-rate ramp on pops so a big combo rises in pitch;
* two looping `MediaPlayer`s for the menu and in-game beds (45 % volume);
* every play call checks `SettingsManager.soundEnabled` / `musicEnabled` first, and
  music pauses when the app goes to the background (`AppServices.onAppForegroundState`);
* nothing is loaded until the app starts, and assets are released in `release()`.

## 5. Static verification tools

| Script | Checks |
| --- | --- |
| `tools/check_patterns.py` | every ASCII level layout: row widths (11/10), symbols, row count, unused keys |
| `tools/check_resources.py` | every `R.*` reference in Kotlin/XML/manifest resolves; no duplicate resources; XML is well-formed; resource file names are aapt2-legal |
| `tools/check_symbols.py` | every import, `Type.member`, method/property call and `override` signature resolves across the UI/engine/render layers |

Run all three before committing:

```bash
python3 tools/check_patterns.py && python3 tools/check_resources.py && python3 tools/check_symbols.py
```

See [VERIFICATION.md](VERIFICATION.md) for what they do and do not cover.
